## 💳 Featured Project

### MOVA

A fintech application designed around **controlled access to money**.

MOVA helps users move money away from their easily accessible balance and release it according to predefined rules and schedules.

**Backend focus:**

- ASP.NET Core
- PostgreSQL
- Redis
- Background processing
- Payment gateway integrations
- Bank payout processing
- Utility payments
- Authentication & authorization
- Transaction processing
- Production reliability

> Building financial software where correctness, reliability and failure handling matter.

## 🏗️ Engineering Interests

I'm particularly interested in:

**Scalability**  
Designing systems that can handle increasing traffic and transaction volume without becoming unnecessarily complex.

**Reliability**  
Building systems that behave predictably when things go wrong — because production eventually will.

**Performance**  
Finding bottlenecks and improving database queries, API response times, background processing and resource usage.

**Production Engineering**  
Debugging real production problems, tracing failures, understanding logs and getting systems back to a healthy state.

**Backend Architecture**  
Designing maintainable services, APIs, workers, data access layers and integrations.
